# 统一主图、文搜文与证据 RAG

2026-11-04。以题找文、以文找文两个入口共用主流程，原文与研究历史仍保存在原 SQLite 数据目录。

## 启动与查看

停止当前旧科研后端（Ctrl+C），再双击根目录 start-scientific.cmd；浏览器 Ctrl+F5。Ollama 继续使用已有 qwen3.5:4b。本机已经确认 bge-m3:latest 存在并成功返回 1024 维向量，独立 .env.scientific 已补充其配置，未改变原模型或密钥。

任务页面底部展开“查看完整工作流与运行诊断”，点击任一主图阶段查看耗时、模型调用、已测 token 和产物计数；“查看主图定义（Mermaid）”显示实际编译图定义。超过 200 条事件会继续分页读取，包含已结束历史任务。没有返回 usage 时显示未测量，不把缺失数值当作零。

/api/pipeline 需本机令牌，返回由真实构图函数生成的定义。离线图见 unified-research-graph.md。

## 执行结构

主图：文献发现 discover → 原文索引 index → 取证与分析 analyze → 范围核验 assess → 报告写作 write → 引用审核 audit → 结果交付 finalize。audit 对程序能检查的未知引用/缺引用最多触发一次写作返工，仍未通过时报告与持久进度均为 partial。

analyze 调用原有 read → synthesize → propose → review 子流程。节点不必都是自主 Agent：过滤、引用完整性和预算由程序执行；规划、相关性、阅读和写作使用模型；原有研究循环仍可用于精读的以题入口。

图状态携带任务引用、计数与路由，SQLite 保存原文和工件。恢复从主图入口重新调度，成功检索、阅读缓存、分析快照和写作进度按内容/模型/规范/实际检索身份复用。当前不是 LangGraph 原生 checkpointer 的逐节点恢复，不承诺模型调用恰好一次。整体执行和可选向量请求都受任务剩余时间限制。

## RAG 的具体应用

1. 文搜文：从论文原文片段生成问题/方法查询，先调用外部学术索引获取候选，再对已有候选做种子—摘要语义排序。第一条研究问题查询中通过相关性筛选的结果优先，随后补充方法查询结果；组内保留时间取样。不把相似度当作引用关系或科学相关性的证明。
2. 阅读：按物理页切分原文窗口，保留 chunk ID、论文 ID、物理页、起始字符、文档哈希、访问层次和来源链接。用 BM25 与本机嵌入的余弦召回排名做 RRF 融合；全文按任务定向选取有限片段，reader 仍校验引文是否出现在原文。未命中时明确记录，再读有限起始原文。
3. 写作：对已经定位的 claims 建立证据索引。精读报告按章节问题召回证据；趋势报告按每篇论文的问题/方法/贡献检索自身证据，随后组装分支与方法表，避免跨论文引用污染。审核器收到正文实际引用的证据，而非固定的前八条。

索引是任务内存对象，不是一个覆盖全球论文的向量库。向量只能检索已经收集的材料，发现最新论文仍依赖 arXiv/OpenAlex。当前最多索引 128 个原文窗口、128 条交错来源证据；窗口 1200 字符、步长 1000，不是真实章节语义解析或公式/表格结构解析。可用窗口数为包含空白窗口的估计上界；截断、模式与降级原因进入结果和事件。

本机 /api/embed：批次最多 16、单条最多 1800 字符、每任务最多 32 批、内存缓存最多 512 条。模型失败或返回错误维度/非有限向量时回退 BM25；取消保持传播，不因此转为成功。降级结果不会覆盖健康混合检索缓存；并发 reader 固定各自实际检索身份后再写缓存。无需下载模型或复制全文到新数据库。

可在 .env.scientific 设置：

```dotenv
SCIENTIFIC_EMBEDDING_BASE_URL=http://127.0.0.1:11434
SCIENTIFIC_EMBEDDING_MODEL=bge-m3:latest
```

将模型值留空可关闭嵌入，仅保留 BM25。目前只允许明确的本机 loopback Ollama 地址。修改配置后重启后端。网页原文查找接口使用 BM25，不在每次页面点击时重建向量库。

## 可选 LangSmith

本地事件记录默认启用，远程追踪默认关闭。需要云端查看时自己在 .env.scientific 填写：

```dotenv
SCIENTIFIC_LANGSMITH_ENABLED=true
LANGSMITH_API_KEY=你的LangSmith密钥
LANGSMITH_PROJECT=scientific-research
```

地区需要时设置 LANGSMITH_ENDPOINT。具体值以自己的 LangSmith 工作区为准；不需要改用云端生成模型。

使用现有 langsmith 0.10.9 的 Client/RunTree，在研究根、主图节点、分析子阶段、真实来源边界、检索、嵌入与模型调用建立父子 span。默认远端只发送摘要哈希、数量、耗时、错误类型及实际模型 usage 和模型名，不上传论文正文、完整提示或模型回答。禁用原生自动全状态追踪，避免分析子图原文随环境变量被自动发送。查询与筛选理由可在本机研究过程、检索审计和已保存工件检查；云端哈希摘要不提供原始提示词逐字查看。

LangSmith 未配置密钥，本次没有声称真实云端连通已验证；已验证可选开关、摘要脱敏、父子关系、用量、取消与发送失败隔离。启用只代表尝试发送，不代表网络投递成功。追踪失败不应中断研究。

生成模型 token 来自接口 usage；失败调用有 usage 时也计入。嵌入输入 token 单独统计，不混入生成模型预算。原有累计调用预算恢复不清零；历史没有用量事件的调用无法追补。Ollama token 数不等于云端账单。

## 验证边界

功能回归、合成 PDF/浏览器流程与真实本机模型试跑完成；正式研究质量评测和消融仍后置。一次真实 qwen+bge 试跑使用保存的真实论文摘要与回放搜索源，83.92 秒、7 次生成调用、输入 14129 / 输出 3938 / 合计 18067 token，嵌入输入 1673 token。7 个主图阶段完整执行，报告有 1 篇逐篇解读；目标是 2 篇，因此外层为 degraded。正文 ready 只代表本次写作产物通过引用完整性路径，语义、实验与期刊级别尚未认证。该试跑不验证新的在线检索或全文抓取。

独立审查发现并修复了事件分页/并发重复、向量总时限、审核遗漏新召回证据、二次引用错误状态不一致、来源追踪遗漏、片段提前全量分配、降级缓存与并发 reader 身份竞态。每项有对应回归用例。真实报告与摘要在聊天 outputs；不覆盖用户研究历史，没有安装依赖或下载模型。
