# 模块优化实施计划（2026-11-08）

用户授权按模块自主完成优化，并希望以源码和结果学习后结合黑马点评面试。沿用既有架构、独立模块增量，避免重写稳定链路。正式质量评测仍后置。

1. 上下文：模型边界统一角色投影、字符预算、结构审计；历史线索只进入 planner/controller。修复 .env 可选配置白名单遗漏。
2. 记忆：新增 SQLite 紧凑研究线索表；仅从非演示真实结果保存来源与检索词，不保存生成结论为事实；按任务快照，恢复不漂移，支持只删记忆。
3. 工具/循环：身份核验、来源版本、持久化无进展状态、明确停止原因、复用已有段落检索。与记忆模块独立并行修改。
4. 报告：结构与来源覆盖诊断、重复段落警告，避免以一个主观分数认证科学结论。
5. 集成：Runner/API 接入、完整离线回归、配置与本机连接烟测；编写源码阅读图、掌握标准、面试演示脚本和真实边界。

各实现先失败回归再修复；不修改黑马点评代码、不下载模型、不自动发布、不上传全文到外部追踪。临时文件仅放本聊天 work，结束清理；保留源码、用户资料、历史与精简验证记录。既有项目 git 元数据不可用，授权原地增量，不复制代码库或虚拟环境。
